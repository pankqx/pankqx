05MethodSchematic · U1 → U5

How I build with AI

AI writes a lot of my code. It doesn't make my decisions. The speed comes from agents working in parallel; the quality comes from the structure I put around them.

PCB · KSP-METHOD · REV A
U1
Spec

Write it down

Brief, data model and acceptance criteria first, in files the agents read.

U2
Slice

Cut it small

Work split into vertical slices, each shippable and testable on its own.

U3
Generate

Build in parallel

Claude Code and Codex build slices side by side, from the spec.

U4
Verify

Read every diff

I review each change. Typecheck, lint and tests run in CI before merging.

U5
Ship

Release by pipeline

GitHub Pages, Vercel, .deb and .exe installers, APKs, all built by CI.

Proof on file

Flow & Magic ships with an AGENTS.md, architecture decision records and 131 automated tests that keep the agents honest.

Tonefer releases are built and tested on Ubuntu and Windows by GitHub Actions before anyone downloads them.
