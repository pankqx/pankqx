Drafting Table

A personal identity for K S Pankaj, built on the language of technical drawing. The idea: an engineer's portfolio should read like a set of drawings. Exact, labelled, measured, and still made by a person.

01MarkMonoline · 12-unit cells
Construction
Rules
StrokesOne weight, square caps, drawn on a 12-unit cell with a 6-unit gap between letters. The S and P share a 2.5-unit chamfer so the set reads as one plotted line.
The padThe orange square is a solder pad: the point where the circuit connects. It is the only colour in the mark and doubles as the full stop on every headline.
Clear spaceOne letter height on every side. Minimum width 40 px on screen, 14 mm in print.
MotionThe mark is plotted, never faded: each letter draws in sequence (0.9 s), then the pad lands.

Signal orange is the colour of a live wire: one accent per view, used for the thing that matters right now. Blueprint mode swaps the papers, never the signal.

06MotionPlotter, not fireworks
DrawLines plot themselves along their path (1.6 s, ease-in-out). Text and fills settle in after the line, never before.
SignalSmall orange pulses travel along traces to show flow: input → process → output. Off-screen drawings pause.
