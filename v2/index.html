02How I work

Enterprise software with AI, in less time, at less cost.

AI is a power tool in my workshop, not the carpenter. It speeds up the typing. The architecture, the reviews and the final call are mine.

  • Spec
  • Slice
  • Generate
  • Verify
  • Ship
how-i-work.ts
// every feature goes through the same five steps
const feature = spec(brief, dataModel, tests);   // written first
for (const slice of split(feature)) {         // small pieces that work alone
  const code = await agents.generate(slice);
  verify(code, slice.tests);                    // tests sign it off, not vibes
}
ship();                                         // then coffee
